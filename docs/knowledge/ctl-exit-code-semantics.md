# exit 1（机器失败）≠ exit 2（用法错误）

控制端要接自动化脚本，退出码必须有清晰语义：

| 退出码 | 含义 | 该怎么做 |
|---|---|---|
| 0 | 全部成功 | — |
| **1** | 至少一台机器失败 | 看逐台结果，重试那几台 |
| **2** | 命令行用法错误 | 改命令，别重试 |

区分它俩的意义：**批量操作时「3 台挂了」和「参数写错了」是两种完全不同的处理**。
写 CI 或脚本时按 `exit 2` 直接失败、按 `exit 1` 进重试/告警分支。

另外：每次动作默认会写 registry 的状态字段（online/offline 回填）。**只想探活时加
`--no-update`**，否则一次无心的高频 ping 会把状态刷成别的值。
