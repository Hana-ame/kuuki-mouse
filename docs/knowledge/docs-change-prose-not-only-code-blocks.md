# 改行为时先 grep 正文的断言句，别只改代码块

把三种传输改成「默认只开 PeerJS」那次，**只换了命令块，正文里「三种传输默认全开」
那句没动** —— 而它是全篇最容易被扫到的一句话，留着等于没改，还比不改更糟（读者会
以为自己理解错了）。

**做法**：改完行为之后，grep 一遍相关的**断言词**（默认 / 全开 / 支持 / 不支持 /
必须），不 grep 代码块。代码块会被校验脚本接住，正文不会。

同理的另一类：**「连别人的工具脚本」**（`wincheck.py`）在本地的同时不会被 CI 跑到，
它们对默认值的假设变更要单独复查。`wincheck.py` 曾经连 8766/50052 却没写前置命令，
默认改了之后照它跑必然连不上。
