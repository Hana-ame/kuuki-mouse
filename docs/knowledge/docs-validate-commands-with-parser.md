# 用真 parser 校验文档里的命令

文档里的示例命令会悄悄失效（曾经抓到 `--op` 这种不存在的写法、`--backend` 这个没有
的参数）。`check_ctl_docs.py` 的做法：

- 抽取出 `remote.ctl` 命令 → 喂给真的 `build_parser()` → 捕获 `SystemExit`
- 全程不联网、不执行副作用

## 刻意只扫代码块，不扫全文

正文里会有「写成 `shot out.png self` 会报错」这种**故意写错的反例**。扫全文会误报，
然后你会为了让数字好看而去改正文，把反例改对了 —— 那就本末倒置了。

**先想清楚「哪些内容是承诺可执行的」**，再决定扫描范围。

## 它管不到的

这只验「parser 认不认得」，**不验参数值的合法性**。曾经 README 里写
`--transport ws --endpoint 192.168.1.5:8765`，parser 认得（字符串参数），但运行期
`validate_endpoint` 会拒（ws 必须 `ws://` 开头）。见下一条。
