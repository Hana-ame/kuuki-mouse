# GUI 自动化的可靠套路：截图闭环

「用 AI 控制真实桌面」可行，前提是不靠盲打：

**截图 → 看图 → 换算坐标 → 操作 → 再截图验证**，每步都验。

## 坐标换算（最容易栽的一处）

Read 工具显示的截图是**缩放过**的：1680x1050 的屏幕会显示成 1080x675，
而 client 接收的是**真实屏幕坐标**。所以图上量出来的坐标要乘 1.5556 再下发。

## 点击必须 move + click 两步

不是风格问题，是被 bug 逼的：见 `protocol-mouse-click-ignores-xy.md`
（`mouse.click` 静默忽略 x/y）。所以正确写法是先 `mouse.move` 再 `click`，
**并且 click 之前用 `mouse.position` 确认光标真的到位**。

## 浏览器操作

- 启动：Win+R 输入 `msedge` 回车，**比点任务栏图标可靠**
- 地址栏：`ctrl+l`
