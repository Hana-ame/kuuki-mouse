# 应用层分块的三个 bug（同一轮里一起抓出来的）

自己实现分块之后，同一轮排查里连续抓到三个问题，全都属于「平时好好的，图一大就错」：

1. **分块 id 撞号** —— 原来只用时间戳生成 id，同一毫秒内的两块 id 相同，接收端拼错。
   改成「时间戳 + 3 位随机数」
2. **`CHUNK_THRESHOLD` 定义了却没用** —— 阈值是个摆设，实际按另一套逻辑在切，
   代码读起来是对的，行为是错的。**定义了常量就一定要有引用它的地方**
3. **分块跨响应交错** —— 两个大响应同时发出时，彼此的分块会混在同一条流里，接收端
   按序号拼就拼到别人的数据

修完之后才是「192KB 截图经真实 DataChannel 分块传送、逐字节相同」这个实测结论。
**所以这个结论必须靠大图验证** —— 小图根本触发不到上述任何一个 bug。
