# 手机端 token 握手：连上先 `{"op":"auth"}`

**曾经的 bug：设了 `--token` 手机端就废。** `web/script.js` 里根本没有 auth 概念，
也没有 `conn.on('data')` —— 服务端鉴权失败后直接 close，页面只会无限重连并显示
「断开中」，用户看不出原因。

现在的握手：连接建立后立刻发 `{"op":"auth"}`，服务端没设 token 时照样回
authenticated，所以两端兼容。URL 支持携带凭证，二维码可以带上：

```
https://<pages>/#/<房间码>?token=<口令>
```

## 鉴权失败要把配对区放回来

配对成功后 `#pair` 会隐藏。而鉴权失败时状态栏写着「改对后点开始配对」——
**用户根本看不到输入框**，只能刷新页面重来。所以鉴权失败时把配对区恢复显示，
那句提示才是可执行的。

> 检查这类问题的办法：把错误提示里让用户做的事，自己按提示走一遍。
